# Bug & Race-Condition Ledger (WinVoxExamBro)

Ringkasan lengkap seluruh hipotesis bug dan *race condition* beserta bukti kode, tes reproduksi (Merah -> Hijau), perbaikan minimal, dan status akhir yang jujur sesuai batas lingkungan Linux vs `windows-latest` CI.

| ID | Komponen & Lokasi | Temuan & Risiko | Severity | Tes Reproduksi / Bukti | Status Akhir |

| H-02 | `RecoveryState.cs` (`BuildPowerShellRecoveryScript`) | `restore-kiosk.ps1` tidak memeriksa proses aktif `ExamBro.Exam` / `LouisVox ExamBro` sebelum mencabut lockdown & `recovery.json`. | **High** | **Merah -> Hijau**: `RecoveryStateConsistencyTests.BuildPowerShellRecoveryScript_ChecksForRunningExamProcessBeforeModifyingPolicies` + `E2E07_H02` | **Terbukti & Diperbaiki** (gagal di baseline `Not found: "Get-Process"`, lolos di Core suite setelah guard ditambahkan) |
